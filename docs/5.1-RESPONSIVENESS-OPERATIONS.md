# 窗口响应修复：实际操作记录

分支：`fix/5.1-window-responsiveness`。日期：2026-10-24。

按要求不运行测试套件；以下记录来自启动真实窗口、公共中继连接及实际执行操作。使用同一 Linux 云宿主上的隔离 Agent 身份，不冒称多台物理电脑。

## 已完成的连接操作

- 桌面输入配对码，完成配对、身份确认及真实 SSH 连接。
- 设置默认设备；立即重试单台及全部已启用电脑。
- 近端逐台断开、用已有配对重新连接；远端逐台暂停和允许重新连接。
- 两项功能分别关闭及恢复，保存的配对继续使用。
- 远端撤销授权、近端取消配对，再重新配对并连接。
- 配对码生成、复制、取消；日志展开、读取、清理、收起。
- 刷新前后设备行保持同一 DOM 节点。
- 五个近端身份连接同一远端，同时实际执行命令。
- 第六个近端请求不抢占已有五条连接；明确替换指定连接后，其他四条仍能执行命令。
- 从远端断开其中一台，其他四台继续执行；恢复连接保留配对。
- 一个近端同时连接五个远端身份，并分别实际执行命令。
- 从近端断开其中一个远端，其他四个仍能执行；第六个目标保持原有名额限制。
- 通过已连接 SSH 的 SFTP 实际写入、读回 8192 字节，内容一致。

## 启动及打包

开发入口沿用 `Start-Dev.cmd` / `Start-Dev.sh`，无需新增复杂构建。Windows 运行包由当前分支复制式打包，解压单文件夹后运行 `Start.cmd`；`Restart.cmd` 可重新打开界面。

Windows 打包流程另外实际安装和启动 SYSTEM 服务、启动打包窗口、读取并恢复开关、重载界面、由服务管理器重启后台。该流程不运行测试套件，结果以关联 Actions 执行记录为准；不能把 Linux 操作记录视作 Windows 管理员功能的实机结果。

当前未操作用户电脑，不声称在用户 Windows 10/11 上测得修复后的延迟。本记录不覆盖所有远程业务工具，只覆盖本次修改涉及的连接操作以及并发执行、SFTP 保留情况。

运行包仅包含运行所需文件；开发缓存、私有凭据、原始日志和截图不上传为运行包附件。
