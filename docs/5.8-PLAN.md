## 需求

云端执行环境随用随丢，请求记录必须保存于独立持久服务。两端未连通时，已被服务确认接收的请求仍可查询；换一台云端后可凭独立账户与授权读取原请求状态。请求需关联唯一 ID 及接收、送达、执行、结果、取消或结果未知等事件。

服务只可确认实际已持久接受的请求，未送达对端的请求不虚构执行日志。有副作用的命令不因消息重投而盲目重放；需要去重、授权和执行状态核对。保留策略、容量耗尽及过期行为必须明确，不得把普通离线消息队列宣传为永久账本。
